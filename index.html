Chapter 03 / 客户端

客户端与可用平台

神兽盛世 提供跨平台接入方案，覆盖主流桌面与移动系统。建议使用与订阅档位一致的客户端版本以获得完整权益。

支持的客户端类型

  • Windows 桌面客户端适用于 Windows 10 及以上系统
  • macOS 桌面客户端适用于 macOS 11 及以上系统
  • iOS 移动客户端适用于 iPhone 与 iPad
  • Android 移动客户端适用于 Android 8 及以上系统
  • Linux 命令行工具适用于常见 Linux 发行版
  • 路由器 OpenWrt 插件适用于已刷 OpenWrt 的家用路由器

如需获取客户端安装包与配置说明，请通过订阅账号内的下载入口或工单渠道获取。本页未提供外部下载链接。

Chapter 04 / 使用流程

从订阅到接入的四个步骤

下面是首次使用 神兽盛世 的标准流程，旗舰版与团队版可获得优先工单支持。

  1. 选择套餐

    在套餐页选择合适的档位，确认按月或按年付费方式。

  2. 获取账号

    付款完成后系统将开通订阅，并在站内消息中下发账号信息。

  3. 下载客户端

    使用订阅账号登录客户端下载页，获取与你系统对应的安装包。

  4. 导入并连接

    在客户端中导入订阅链接，选择节点后即可开始使用。

Chapter 05 / 读者来信

常见问题

下面是订阅前最常被问到的问题，分两栏整理。如果下面没有你的问题，可以通过工单联系。

三个套餐之间能升级或降级吗？

可以在订阅有效期内申请升降级，系统会按剩余天数计算差价，并在下一个计费周期切换至新档位。

按年付费和按月付费有什么区别？

按年付费一次性结算一年费用，价格与按月续订十二个月的总价相当，适合长期使用；按月付费更灵活，可随时取消。

每月流量用完后还能继续使用吗？

当月流量用至上限后，连接会按既定规则暂停。可在下一计费周期开始时恢复，或在套餐页购买流量包叠加。

同时在线设备数是否包含路由器？

路由器作为一台设备计入手同时在线数；其下挂设备不再单独计数，但实际可用带宽受套餐档位与线路影响。

团队版是否提供发票或对公付款？

团队版支持企业定制路由与专属客户经理服务，关于发票与对公付款方式，可在工单中与专属经理沟通具体方案。

遇到连接问题应该怎么处理？

建议先在客户端切换节点并检查本地网络；如问题持续，可提交工单，旗舰版与团队版将获得优先处理。

是否提供退款？

退款规则与例外情况以购买页面与服务协议为准，详情可在订阅前查阅相关说明。

可以在哪些地区使用？

神兽盛世 面向有合规跨境网络需求的个人与团队开放，实际可用性以你所在地区的网络环境与相关法规为准。
